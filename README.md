SQL PostgreSQL: Celestial Bodies Database

A fully relational database designed and populated as part of the freeCodeCamp Relational Database Certification curriculum. 
This project models a detailed cosmic system containing galaxies, stars, planets, moons, and planetary classifications while 
enforcing strict relational integrity, custom data types, foreign key constraints, and unique indexes.

📌 Project Overview
The objective of this project is to build a structured database named universe using PostgreSQL. The schema accurately reflects 
real-world astronomical hierarchies and relationships—mapping how galaxies contain star systems, stars host planets, and planets anchor celestial moons.

Key Highlights
DBMS: PostgreSQL
Database Name: universe
Tables Created: 5 (galaxy, star, planet, moon, planet_types)
Data Integrity: Primary keys (SERIAL), foreign keys (REFERENCES), UNIQUE constraints, NOT NULL validations, and varied data types (INT, NUMERIC, TEXT, BOOLEAN).
